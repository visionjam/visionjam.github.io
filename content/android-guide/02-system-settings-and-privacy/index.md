## 2. 系统设置：广告、通知、权限、隐私

### 2.1 关闭系统广告与推荐（HyperOS 3）

HyperOS 的广告开关分散在系统设置和各个系统应用里，没有一个“一键全关”的按钮。目标是把广告减少到可接受，而不是清零。按下面的顺序过一遍，**系统级和应用内两边都要关**：

| 顺序 | 位置 | 具体操作 |
| ---: | --- | --- |
| 1 | 设置 → 隐私保护 → 广告与隐私 | 关闭“个性化广告推荐”；删除/重置广告标识符 |
| 2 | 设置 → 密码与安全 → 系统安全 → 广告服务 | 关闭“广告服务”“系统工具广告”等开关 |
| 3 | 应用商店 → 我的 → 设置 | 关闭“推荐”“广告”“热门内容”；自动更新按需 |
| 4 | 主题壁纸 → 我的 → 设置 | 关闭“广告推荐”“内容推荐” |
| 5 | 音乐/视频/浏览器/天气/日历/下载管理/手机管家 → 各自设置 | 找“广告”“推荐”“热点推送”并关闭（常见叫法：广告推荐、内容推荐、热门推荐、个性化推荐） |
| 6 | 长按桌面空白处/双指捏合 → 桌面设置 → 负一屏 / 搜索 / 文件夹 | 关闭“推荐卡片”“热门推荐”“搜索推荐” |
| 7 | 设置 → 通知与控制中心 → 应用通知 | 关闭营销/推荐类通知渠道，保留聊天/支付/验证码；渠道怎么关见 2.2 |

几点说明：

- **系统级和应用内是两套开关**：系统级关了，应用商店、主题、音乐等仍可能有自己的推荐开关，两边都要关。
- **小米账号里的“隐私协议/声明与条款”只是协议文档，不是开关页**；个性化推荐主要在系统级“广告与隐私”和各应用内关闭。找不到就跳过，不要把它当成开关。
- **关闭个性化推荐不等于没有广告**：只是不再基于你的行为定向，系统应用内仍可能出现非个性化广告/推荐。配合关闭传感器权限，可以减少“摇一摇”开屏广告（见 2.3）。
- 找不到时，用设置顶部搜索框搜“广告”“推荐”“个性化”“体验计划”。HyperOS 版本不同，菜单名会有差异，以你手机上的实际开关为准。
- 开屏广告通常是应用内广告，系统设置关不掉；可以用 GKD 等工具跳过，或用官方会员/官方去广告版。不要用破解版、修改版或非官方去广告版。
- 系统更新后，部分开关可能被重新打开，建议每季度复查一次。
- 原生 Android 对应位置：设置 → 隐私 → 广告 → 删除广告 ID；Google 设置 → 广告。

### 2.2 通知治理

通知是最影响日常体验、又最容易被忽视的一项。做法：

1. 下拉通知栏，长按一条通知 → 进入该应用的通知设置 → 只关闭营销/推荐类“通知渠道”，保留聊天、支付、验证码等关键渠道。
2. 设置 → 通知与控制中心 → 应用通知，按应用检查：哪些应用根本不需要通知，直接关掉总开关。
3. 锁屏通知：敏感应用设为“隐藏内容”或“不显示”。
4. 悬浮通知：只留给即时通讯和闹钟；购物、资讯类一律关闭。
5. 每月做一次“通知审计”：过去一个月哪些应用推送最多，关掉其中不需要的。

> 注意：关闭通知不等于禁止后台。某些应用被关通知后仍会在后台活动；要限制后台，请看第 3 节。  
> 验证码可能走短信、微信、银行 App 推送或邮箱；关闭通知时保留这些渠道，别为了清净把验证码也关掉。

### 2.3 权限治理

Android 的运行时权限大致分三档：**始终允许、仅在使用时允许、拒绝**。大多数应用只需要“仅在使用时”。

| 权限 | 建议 |
| --- | --- |
| 位置 | 导航、打车、天气可“仅在使用时”；社交、购物一般“拒绝”或“仅使用时” |
| 相机/麦克风 | 除拍照、录音、视频通话外，默认拒绝；用时再授权 |
| 通讯录/通话记录 | 只有通讯录备份、来电识别类应用需要 |
| 短信 | 只有短信备份、验证码类应用需要；普通应用拒绝 |
| 照片/视频 | 优先用系统照片选择器，只给选中的照片，不给整个相册 |
| 附近设备/蓝牙 | 只有耳机、手环、车机类应用需要 |
| 身体传感器/健康 | 只有健康、运动类应用需要 |
| 传感器/运动与方向 | 购物、资讯、社交类拒绝；计步/AR/游戏/导航按需 |

特殊权限要单独看：

- **悬浮窗**：除了即时通讯、录屏、翻译，其他尽量关。
- **无障碍**：权限极大，只给可信工具（如 GKD、自动化工具），并定期检查。
- **通知使用权**：只给手环、通知同步类应用。
- **使用情况访问**：只给屏幕时间、专注类应用。
- **设备管理**：只给查找设备、企业管控类应用。
- **安装未知应用**：只给文件管理器、应用商店类应用，且尽量用系统安装器。

> 关闭“传感器/获取设备运动与方向”权限，可以减少部分应用的开屏“摇一摇”广告。HyperOS 路径：设置 → 应用设置 → 授权管理 → 权限管理 → 传感器（名称随版本变化）。注意计步、AR、游戏、导航可能需要传感器，按需保留。  
> 原生 Android 对应入口：设置 → 安全与隐私 → 隐私 → 特殊应用权限（部分版本在“应用”下）。

### 2.4 隐私设置

- **隐私仪表盘**：设置 → 隐私保护 → 隐私仪表盘，看过去 24 小时谁用了相机、麦克风、位置（原生 Android：设置 → 安全与隐私 → 隐私 → 隐私仪表盘）。
- **位置精度**：不需要精确位置的应用，给“大致位置”。
- **Wi-Fi/蓝牙扫描**：关闭 Wi-Fi 或蓝牙后，仍允许扫描会带来额外功耗和位置推断，不需要时关掉。
- **剪贴板**：Android 13+ 会提示读取剪贴板的应用；频繁读取剪贴板的应用要警惕。
- **广告标识符**：系统级删除/重置；Google 设置里也有独立开关。
- **诊断与体验计划**：设置里搜索“用户体验”“诊断”“分析”，按需关闭。
- **输入法**：输入法能看到你输入的一切。尽量选可信输入法，关闭联网联想/云同步；对隐私敏感的场景可用系统自带或离线输入法。
- **私人 DNS**：设置 → 网络与互联网 → 私人 DNS，填可信的 DoT 服务商主机名；不确定就保持“自动”。

### 2.5 桌面与交互

- **动画缩放**：开发者选项 → 窗口动画缩放、过渡动画缩放、Animator 时长缩放，设为 0.5x。不要设 0：动画是操作反馈的一部分，完全关掉会让界面显得“跳”。
- **刷新率**：设置 → 显示 → 屏幕刷新率，选“智能切换”或 120Hz。省电模式可能会强制降到 60Hz，用“显示刷新率”确认。
- **显示大小/字体**：适当调大可以减轻眼睛负担，但过大可能导致布局错位，改完多开几个应用看看。
- **减少动态效果**：动态壁纸、过多小组件、负一屏推荐都会增加常驻开销；不需要就关。
- **深色模式**：OLED 屏幕下深色模式更省电，但不必为了省电牺牲可读性。

| 项目 | HyperOS 3 | 原生 Android |

| 通知 | 设置 → 通知与控制中心 | 设置 → 通知 |
| 权限管理 | 设置 → 应用设置 → 授权管理 | 设置 → 安全与隐私 → 隐私 → 权限管理器（部分版本在“应用”下） |
| 特殊权限 | 设置 → 应用设置 → 授权管理 → 特殊权限 | 设置 → 安全与隐私 → 隐私 → 特殊应用权限（名称随版本变化） |

### 2.7 原生 Android 快速路线

如果你用的是 Pixel、AOSP 或其他接近原生的系统，可以按这张表走；HyperOS 专属的小节可以跳过。

| 任务 | 原生 Android 路径 |
| --- | --- |
| 关广告 ID | 设置 → 隐私 → 广告 → 删除广告 ID |
| 通知 | 设置 → 通知 → 应用通知 |
| 权限 | 设置 → 安全与隐私 → 隐私 → 权限管理器 / 特殊应用权限（部分版本在“应用”下） |
| 隐私仪表盘 | 设置 → 安全与隐私 → 隐私 → 隐私仪表盘 |
| 权限审计 | 设置 → 安全与隐私 → 隐私 → 权限管理器 |
| 电池优化 | 设置 → 应用 → 选择应用 → 电池 → 不受限制/优化/受限 |
| 自适应电池 | 设置 → 电池 → 自适应电池 |
| 私人 DNS | 设置 → 网络和互联网 → 私人 DNS |
| 开发者选项 | 设置 → 关于手机 → 连点版本号 7 次 → 系统 → 开发者选项 |
| 刷新率 | 设置 → 显示 → 刷新率/平滑显示 |
| 存储 | 设置 → 存储 |
| 工作资料 | 用 Shelter 或系统自带的工作资料功能创建；或由单位的管理配置添加（原生设置没有直接入口） |

> 原生 Android 没有统一的“自启动/关联启动”开关；第 3.5 节的这两列在原生上跳过，改用电池优化/后台限制（3.3），或借助 Shizuku/Hail 等工具。


## 7. 隐私、网络与隔离

### 7.1 权限审计

每月一次：

- 设置 → 隐私保护 → 隐私仪表盘，看相机、麦克风、位置的高频访问者；
- 设置 → 应用设置 → 授权管理，按权限查看哪些应用拥有敏感权限；
- 撤销三个月没用的应用的敏感权限；
- 检查无障碍、设备管理、通知使用权、悬浮窗这四个“高权限入口”。

> 原生 Android 对应入口：设置 → 安全与隐私 → 隐私 → 隐私仪表盘 / 权限管理器。

### 7.2 私人 DNS / VPN / 代理

- **私人 DNS**：使用可信的 DoT 服务商；公司/校园网络可能拦截，失效时切回“自动”。
- **VPN**：只使用可信服务；银行、支付类应用不要走不明代理。
- **远程访问与科学上网**：Tailscale 适合远程访问自家设备；科学上网工具按需选择。注意规则和证书，不要在不可信 Wi-Fi 下关闭 TLS 校验。
- **公共 Wi-Fi**：关闭自动连接；必须使用时优先开 VPN；注意门户认证页面可能是钓鱼。

### 7.3 工作资料与隔离

- **工作资料/Shelter**：把高风险或来源不明的应用放进独立用户空间，限制其访问个人数据；不用时可整体冻结。
- **应用双开/手机分身**：方便，但会复制后台进程和存储占用；不用的分身及时关闭。
- **多用户**：给家人临时使用时可开访客/子用户，避免动到主空间数据。

### 7.4 应用来源与签名

- 优先官方应用商店、F-Droid、GitHub Releases、Obtainium 等可验证来源。
- 安装前看权限和开发者；破解版、修改版、非官方去广告版风险极高。官方付费会员/官方去广告版不在此列。
- 同一应用从不同来源安装时，签名不一致会导致无法覆盖安装或数据丢失。
- 定期检查“安装未知应用”权限，别让文件管理器长期持有。

### 7.5 备份与加密

- 屏幕锁、指纹/面部、查找设备、紧急信息都建议开启。
- 重要数据至少两份：本地 + 云端/ NAS；定期做恢复演练。
- 备份文件加密；不要把未加密的完整备份放在公共网盘。
- 换机前先确认聊天记录、照片、双重验证器（2FA）能迁移；2FA 应用通常需要单独导出/迁移。
