> 对应第 0–1 节。  
> 适合：想让手机更稳定、省电、顺滑，但不想一上来就刷机的人。  

优化不是堆工具，也不是把后台杀光。先想清楚目标、风险和自己手机的真实瓶颈，再动手。

先给结论：

- 优化的第一目标不是“跑分更高”，而是**稳定、续航、流畅、隐私**四件事的平衡。
- 大多数“卡、耗电、存储不够”的问题，靠系统设置就能解决大半；adb / Shizuku 只处理系统设置够不到的部分。
- 不要一上来就卸载预装、杀后台、装清理大师。先体检，再按风险从低到高改。
- 任何改动都要能回滚：先备份、一次只改一项、记录命令。

## 开始之前：这份指南怎么用

这份指南给的是方法和经验，不是唯一答案。手机型号、系统版本、应用更新都会让菜单和命令变化；遇到对不上的地方，**主动查证，不要硬套**。

- **先查官方说明**：厂商设置路径、应用权限、命令语法，以官方文档和应用内说明为准。
- **看真机演示**：B 站、YouTube 有大量真机操作视频，适合确认菜单路径和实际效果；注意视频的机型和系统版本，别把旧版路径当当前版。
- **用 AI 做交叉验证**：把机型、系统版本、报错信息一起发给 AI，让它给出排查步骤；AI 也会出错，重要操作至少用两个来源交叉确认。
- **看真实反馈**：酷安、XDA、GitHub Issues、Reddit 等能看到具体机型的坑；注意辨别广告和引流内容。
- **改动前先备份、先小范围测试**：网上的“一键脚本”先读一遍；看不懂就不运行。
- **注意时效**：HyperOS/Android 大版本更新后，旧教程可能失效；以你手机上的实际界面为准。

## 0. 先建立正确的优化观

### 0.1 四个目标，排序很重要

| 优先级 | 目标 | 判断标准 |
| --- | --- | --- |
| 1 | 稳定 | 不闪退、不重启、通知不丢、支付和通话正常 |
| 2 | 续航 | 待机掉电可控，亮屏时间够用，发热不异常 |
| 3 | 流畅 | 常用应用冷启动快，滑动不掉帧，后台切换不重载 |
| 4 | 隐私 | 权限最小化，广告标识符可控，敏感数据不外流 |

为了“看起来更流畅”而牺牲稳定性，是最常见的优化翻车方式。一个会漏消息、支付闪退的手机，跑分再高也没有意义。

### 0.2 三类手段，风险完全不同

| 层级 | 手段 | 典型操作 | 风险 | 可逆性 |
| --- | --- | --- | --- | --- |
| L1 | 系统设置 | 关广告、管通知、限权限、电池策略 | 低 | 随时改回 |
| L2 | adb / Shizuku | 停用预装、卸载当前用户、appops、settings | 中 | 大多可逆，需记命令 |
| L3 | root / 模块 / 内核 | 改分区、调度、超频、去温控 | 高 | 可能变砖、丢保修、触发风控 |

本文只讨论 L1 系统设置和 L2 adb/Shizuku。L3（root / 模块 / 内核）风险高、可逆性差，不在本文讨论范围内；如果你要尝试，请先准备官方线刷包、恢复方案和备用机。

### 0.3 三条纪律

1. **先备份**：照片、聊天记录、重要文档、应用数据，以及当前的包列表。
2. **一次只改一项**：改完观察 24–48 小时，确认没有通知延迟、耗电反增、功能异常。
3. **记录改动**：日期、包名、动作、原因、回滚命令。出问题时，这份记录比记忆可靠。

### 0.4 先记录自己的基线

不用和别人比，先记录自己的：待机 8 小时掉电、亮屏时长、可用存储、常用应用冷启动、异常发热场景。改完一周后再对比。

### 0.5 优化顺序

```text
体检 → 系统设置（广告/通知/权限） → 后台/省电 → 存储 → 流畅度/显示 → adb/Shizuku → 复盘
```

先解决最痛的那个点。如果主要是存储不够，就先做第 4 节；如果是待机掉电，就先做第 3 节。不要为了“全套做完”而一次改几十项。


## 1. 体检：先找到真正的瓶颈

### 1.1 系统自带的三张表

**电池**：设置 → 电池 → 耗电排行 / 耗电曲线。重点看：

- 待机时谁在唤醒手机；
- 移动网络信号差时，基带耗电是否异常；
- 某个应用的后台耗电是否长期排在前列；
- 充电时是否异常发热。

**存储**：设置 → 存储。先看分类占比，再看“应用”里谁占得最多。保持至少 10%–15% 的空闲空间，系统更新、缓存和文件系统都需要余量。

**屏幕使用时间**：设置 → 数字健康与家长控制。看解锁次数、通知数量、使用时长。很多“手机变卡”的体感，其实是使用强度变了。

> 原生 Android 对应入口：设置 → 电池 → 电池用量；设置 → 存储；设置 → 数字健康与家长控制（名称随版本略有不同）。

### 1.2 开发者选项里值得看的

开启方式：设置 → 我的设备 → 全部参数与信息 → 连续点按“OS 版本”（部分版本是“版本号”）7 次，然后到 设置 → 更多设置 → 开发者选项。原生 Android：设置 → 关于手机 → 连点“版本号”7 次 → 系统 → 开发者选项。

值得临时打开的：

- **显示刷新率**：确认当前是 60Hz 还是 120Hz，以及何时掉回 60Hz。
- **GPU 渲染模式分析**：看界面是否掉帧，只在排查时开。
- **后台进程限制**：只用于调试，**不要长期开启**（原因见 5.5）。
- **不保留活动**：只用于开发调试，日常开启会让应用频繁重载。

### 1.3 adb 辅助（可选）

如果你已经会 adb，可以用两三条命令看电池和内存；本文不展开复杂命令：

```bash
adb shell dumpsys battery
adb shell dumpsys meminfo | head -n 40
```

更细的耗电分析用系统电池面板或 bugreport；bugreport 含设备信息，不要上传到不可信服务。
